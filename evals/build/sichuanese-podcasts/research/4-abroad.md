## D. RSS and 小宇宙

- Standard RSS feeds exist for any show whose host exposes one. Shows hosted by 小宇宙's own hosting have public feeds at feed.xyzfm.space/<id>: example https://feed.xyzfm.space/mwtfernt99uy (海椒Radio) fetched OK from outside China on 2026-10-07 — standard RSS: title 海椒Radio, language zh-cn, author 韩老人, 91+ items, Vol.091 pubDate Thu 27 Aug 2026, m4a (MP4 audio) enclosures. Apple Podcasts uses the same feeds (feedUrl in the iTunes API for many shows is feed.xyzfm.space/...).
- 小宇宙 itself does not appear to show an RSS link per show: the Podwise blog (https://podwise.ai/blog/xyzfm-and-podwise, 2023-12-01) says "Podwise 导入小宇宙节目时，背后也是通过 RSSHub 来获取 RSS 链接的"; RSSHub has a route /xiaoyuzhou/podcast/:id that scrapes https://www.xiaoyuzhoufm.com/podcast/{id} (embedded Next.js JSON, no auth) — https://github.com/DIYgod/RSSHub/tree/master/lib/routes/xiaoyuzhou (podcast.ts, pickup.ts, namespace.ts), read 2026-10-07. => a third-party-generated feed is possible; FLAG: public RSSHub instances can be rate-limited/blocked and I did not test an audio download from a 小宇宙 CDN link from abroad.
- 小宇宙 also imports external RSS: pasting a feed URL into the search box subscribes (secondary sources: ifanr / search snippets). Creators get onto 小宇宙 by submitting an RSS link (sspai, 2020-11-30: "节目想要上线苹果播客、小宇宙都要提交RSS链接"), so most shows originate from an external RSS host (Buzzsprout, Lizhi, Ximalaya, Typlog etc.) whose feed works in any app.
- Ximalaya shows have feeds of the form http://www.ximalaya.com/album/<id>.xml (as in the Apple directory entries) — I did not test whether those work from abroad. 荔枝: rss.lizhi.fm/rss/<id>.xml. 蜻蜓FM: papi.qingting.fm/podcast/channels/<id>.
